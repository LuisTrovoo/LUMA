# Referencias cientificas

Esta pasta organiza os artigos e referencias usados no desenvolvimento cientifico do projeto.

## Politica

- Preferir DOI, PMID ou link oficial em vez de armazenar PDFs protegidos por copyright no repositorio publico.
- PDFs com permissao de redistribuicao podem ser colocados em `references/papers/`.
- Toda referencia efetivamente citada no artigo deve entrar em `references/references.bib`.
- O arquivo `literature-notes.md` pode registrar por que cada trabalho e relevante para o projeto.

## Separacao importante

As referencias cientificas documentam o metodo e a comparacao bibliografica. Elas nao fazem parte do executavel do aplicativo.
